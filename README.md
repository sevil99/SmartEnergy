# SmartEnergy — 3D-прототип

Первый прототип просмотра модели `Engine.glb`: вращение, масштабирование, выбор одной из 12 деталей и просмотр показателей.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173/`). Для проверки сборки: `npm.cmd run build`.

В PowerShell используйте `npm.cmd`: команда `npm` может пытаться запустить заблокированный системой файл `npm.ps1`. Менять политику выполнения сценариев для этого не требуется. На этом компьютере зависимости уже установлены, поэтому сейчас можно сразу выполнить `npm.cmd run dev`.

## Модель

Оригинал находится в `3d  model/Engine.glb` (между `3d` и `model` два пробела). Для работы сайта его копия лежит в `public/Engine.glb`. После обновления оригинала скопируйте новую версию в `public/Engine.glb`.

Файл содержит 12 отдельных узлов с именами `empty_2`…`empty_13`. Их названия и показатели находятся в [`src/data/engine.json`](src/data/engine.json): `empty_2` — блок цилиндров, `empty_3`…`empty_12` — головки цилиндров 10…1 в обратном порядке, `empty_13` — маховик. При изменении модели обновляйте в JSON поле `node`, если экспортёр поменяет имена узлов.

Показатели и статус `attention` у головки цилиндра 10 задаются вручную в JSON. Пороговые значения и подключение к источнику телеметрии пока не реализованы.
