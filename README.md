# SmartEnergy — 3D-прототип

Первый прототип просмотра модели `Engine.glb`: вращение, масштабирование, выбор одной из 12 деталей и просмотр её технических данных.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173/`). Для проверки сборки: `npm.cmd run build`.

В PowerShell используйте `npm.cmd`: команда `npm` может пытаться запустить заблокированный системой файл `npm.ps1`. Менять политику выполнения сценариев для этого не требуется. На этом компьютере зависимости уже установлены, поэтому сейчас можно сразу выполнить `npm.cmd run dev`.

## Модель

Оригинал находится в `3d  model/Engine.glb` (между `3d` и `model` два пробела). Для работы сайта его копия лежит в `public/Engine.glb`. После обновления оригинала скопируйте новую версию в `public/Engine.glb`.

Файл содержит 12 отдельных узлов с именами `empty_2`…`empty_13`. Пока интерфейс показывает их как «Деталь 1»…«Деталь 12». Перед подключением данных стоит дать узлам осмысленные и стабильные имена в редакторе модели, например `Cylinder_01` или `Flywheel`, и повторно экспортировать GLB. Это позволит связать конкретный узел с датчиками без привязки к порядку объектов в файле.

Телеметрия в текущей версии не подключена. Инспектор показывает только сведения из самой модели.
